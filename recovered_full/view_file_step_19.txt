1: # 🛡️ NetGuard Bharat
2: 
3: NetGuard Bharat is a real-time network monitoring dashboard and data exfiltration visualizer. It monitors outbound socket connections, runs a passive packet-sniffing tap in the background, and maps network traffic dynamically onto an interactive 3D globe. 
4: 
5: The project is built to help identify anomalous outbound traffic, track where local processes are sending data, and provide threat mitigation guides.

9: ## 🚀 Key Features
10: 
11: ### 🌍 Interactive 3D Globe
12: *   Built with React, Vite, and Three.js.
13: *   Plots active outbound connections as glowing lines connecting India to target countries based on their destination IPs.
14: *   Includes automatic performance capping (rendering a maximum of 30 active arcs at a time) to avoid browser lag.
15: 
16: ### 📡 Real-Time Socket Monitoring & Express Backend
17: *   A lightweight Node.js server that polls current socket connections using native OS tools (`netstat` and `tasklist`).
18: *   Maps active connection PIDs to executable application names, using a 5-second process name cache to minimize CPU usage.
19: *   Streams socket data in real time via Socket.IO to the client dashboard.
20: *   Exposes an `/api/alert` POST route to receive and display behavioral flags from external network taps.
21: 
22: ### 💾 SQLite Telemetry Persistence & Dynamic Retention
23: *   **Persistent SQLite DB**: Transitions the application from a stateless frontend visualizer to a stateful enterprise dashboard, storing telemetry in `netguard_telemetry.db`.
